# VKRB Kutsenko

Используемый датасет: [HyperLeaf2024](https://www.kaggle.com/competitions/HyperLeaf2024)

Код предполагает перевод датасета из формата .tiff в numpy через `to_numpy.py`, в pytorch/imp/data можно посмотреть пути сохранения/указать свои.

Команда для запуска tensorboard:
```
tensorboard --logdir results/logs/
```
